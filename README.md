# 📌 To-Do List using Doubly Linked List in C++

## 🧠 About the Project  
This is a simple **To-Do List** project implemented using **Doubly Linked List** in C++.  
It showcases dynamic task management without using STL containers like `std::vector` or `std::list`.

---

## 🎯 Features

- ✅ Add new tasks  
- 📝 Edit existing tasks  
- ❌ Delete tasks  
- 📋 Display all tasks  
- 🔄 Traverse tasks forward and backward  
- 💾 Clear the whole list

---

## ⚙️ Technologies Used

- **C++**
- Console-based application (No GUI)
- Object-Oriented Programming
- Manual memory management (no STL)

---

## 📚 Learning Objectives

- Mastering Doubly Linked List operations (insert, delete, traversal)
- Understanding pointer manipulation in C++
- Applying OOP concepts to data structures
- Practicing clean code organization and modular design
